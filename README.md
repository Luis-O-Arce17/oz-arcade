# OzArcade

OzArcade is a web-based arcade platform built with HTML, CSS and JavaScript.

The project is designed to progressively incorporate classic-inspired browser games while keeping each game reasonably independent and easy to maintain.

## Project Status

OzArcade is currently under development.

## Goal

Build a modular arcade platform where new games can be added without unnecessarily modifying existing ones.

## Running the Project

For now, the project can be opened directly through `index.html`.

During development, using a local server such as Live Server for Visual Studio Code is recommended.
